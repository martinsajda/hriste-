# Architektura macOS varianty
Node.js 22.13+ s Express 5 servíruje statické `public/` i JSON API na localhost:3000. SQLite databáze `data/contacts.db` vzniká automaticky přes `node:sqlite` (`DatabaseSync`). Bez ORM, bez SQL Serveru, bez IIS, bez build kroku frontendového kódu. Backend je synchronní a vhodný pouze pro malou lokální demonstraci. Server binduje 127.0.0.1. Aplikace neobsahuje autentizaci ani šifrování databázového souboru, proto je určena jen pro lokální testovací data.
